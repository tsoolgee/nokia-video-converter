# ממיר סרטונים לנוקיה

תוכנה לווינדוס שהופכת כל סרטון לקובץ שטלפון נוקיה פשוט (כמו Nokia 215 4G) יודע לנגן.

גוררים לחלון תיקייה, כמה תיקיות או סרטונים בודדים, וכל הסרטונים מומרים באותו מבנה תיקיות בתוך תיקייה חדשה בשם "‎<שם התיקייה> - נוקיה‎", שנוצרת ליד המקור. המקור לא משתנה.

## הורדה

את הקובץ `NokiaConverter.exe` מורידים מ[עמוד ההורדות](../../releases/latest). לא צריך להתקין כלום, והכל כבר בתוך הקובץ.

## מה התוכנה עושה

- **גרירה או בחירה:** אפשר לגרור תיקיות וקבצים לחלון, או לבחור אותם בכפתורים.
- **כמעט כל סוג וידאו:** MP4, MKV, AVI, MOV, WEBM, WMV, FLV, MPG, RMVB, 3GP ועוד עשרות סוגים.
- **מבנה התיקיות נשמר:** כל תת-תיקייה במקור מופיעה גם בתיקיית הפלט.
- **סרטונים שכבר הומרו לא מומרים שוב.**
- **קובץ פגום או מוגן** מסומן כ"נכשל", וההמרה ממשיכה לקובץ הבא.
- **התקדמות:** באחוזים, עם שם הסרטון שמומר עכשיו. החלון לא נתקע בזמן ההמרה.
- **ערכת נושא:** בהירה, כהה, או לפי הגדרת המחשב.

## הגדרות (כפתור גלגל השיניים)

- **תיקייה חדשה ליד המקור** (ברירת המחדל): נוצרת תיקייה "‎<שם> - נוקיה‎", והמקור לא משתנה.
- **החלפת הקבצים בתיקיית המקור:** כל סרטון מוחלף בגרסת הנוקיה שלו, באותו מקום. הקבצים המקוריים עוברים לסל המחזור, ואפשר לשחזר אותם משם. סרטון שכבר בפורמט של נוקיה לא מומר שוב.

## הפורמט

MP4 עם MPEG-4 Part 2, ברזולוציה 320×240 ו-25 פריימים לשנייה, ושמע AAC סטריאו. סרטון רחב או אנכי מקבל פסים שחורים, כדי שהתמונה לא תימתח.

## בנייה מהקוד

```
pip install pywebview pyinstaller imageio-ffmpeg
python build.py
```
